# Learn JavaScript, TypeScript, and Playwright

A collection of small, standalone examples for learning JavaScript fundamentals. Lessons are organized by chapter and numbered in sequence so you can work through them in order.

## Requirements

- [Node.js](https://nodejs.org/) installed and available on your `PATH`

## Running an example

From the repository root, run an individual JavaScript file with Node.js:

```sh
node 01_chapter_JS_Basics/01_HelloWorld.js
```

Each file is intended to be explored on its own. Edit an example and run it again to see how the output changes.

## Chapters

| Directory | Topics |
| --- | --- |
| `01_chapter_JS_Basics` | Hello World and basic arithmetic |
| `02_chapter_JS_Keyword` | JavaScript execution, variables, identifiers, and comments |
| `03_chapter_JS_Literals` | Literals, numbers, `null`, and `undefined` |
| `04_chapter_JS_Operators` | Assignment, arithmetic, comparison, logical, string, and conditional operators |
| `05_chapter_Incre_Decre_Op` | Increment, decrement, and nullish coalescing |

The repository is a learning collection rather than a packaged application; there is currently no build or test command.
